### 🔗 **[⬇️ تحميل المشروع من GitHub](https://github.com/pharmacynafis-ops/Coputer_USE_AI_Agent.Prototype/releases/tag/v1.0.0)**

</div>

---

### `الخطوة 2` — الحصول على OpenRouter API Key

يستخدم CompLoca خدمة **OpenRouter** للوصول إلى نماذج الذكاء الاصطناعي، لذلك تحتاج إلى مفتاح API خاص بك.

**اتبع الخطوات التالية:**

1. اذهب إلى 🔗 **[https://openrouter.ai/keys](https://openrouter.ai/keys)**
2. سجّل دخولك أو أنشئ حساباً مجانياً
3. اضغط على **Create Key** للحصول على مفتاحك
4. انسخ المفتاح واحتفظ به

بعدها افتح ملف الإعدادات داخل مجلد المشروع وضع مفتاحك فيه:

```env
OPENROUTER_API_KEY=sk-or-xxxxxxxxxxxxxxxxxxxxxxxx
```

> [!IMPORTANT]
> لا تشارك مفتاح الـ API مع أحد، ولا ترفعه على GitHub.

---

### `الخطوة 3` — تشغيل الخادم

افتح **Command Prompt** داخل مجلد المشروع، ثم نفِّذ الأمر التالي:

```bash
python server.py
```

> [!WARNING]
> إذا ظهرت لك أي أخطاء، تأكد من أنك فتحت **سطر الأوامر (CMD)** داخل نفس مجلد المشروع تحديداً، وليس من مكان آخر.

---

### `الخطوة 4` — ابدأ التحكم! 🎉

افتح متصفحك وانتقل إلى:

```
http://127.0.0.1:8000
```

الآن يمكنك إرسال أوامر للوكيل بلغة طبيعية، مثل:

```
Create a folder in the path E:\Example
```

```

```
